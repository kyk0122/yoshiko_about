「よしこについて」公開Webページ

使い方
1. index.html をブラウザで開くと確認できます。
2. 公開するときは、このフォルダの中身をそのままGitHub Pages等へ置けます。
3. 文章は index.html の日本語部分を直接編集してください。
4. よしこの画像は images フォルダへ yoshiko.png という名前で置いてください。

構成
- index.html：本文とページ構造
- style.css：色・レイアウト・スマートフォン表示
- images/yoshiko.png：よしこの画像（後から追加）

JavaScript、外部API、Cookie、フォーム、アクセス解析は使用していません。
